# Changelog

All notable changes to `cafehistoire/laravel-cafe-blog` are documented here.

## [1.0.0] — 2024-01-01

### Added
- Initial release
- Blog frontend with posts, categories, authors, comments
- Filtering by coffee origin (11 origins) and historical era (5 eras)
- Elegant espresso theme with Playfair Display + Lora typography
- Full admin panel (dashboard, CRUD posts/categories/authors/comments)
- REST API with JSON responses
- RSS feed and XML sitemap
- Reading time calculator
- Session-throttled view counter
- Social sharing (Twitter/X, Facebook, LinkedIn, WhatsApp)
- Full-text search
- Author profiles
- Nested comments with moderation
- Spatie Tags integration
- Spatie Sluggable integration
- Pest PHP test suite (Feature + Unit)
- GitHub Actions CI (PHP 8.1/8.2/8.3 × Laravel 10/11)
- French (fr) + English (en) translations
- Install and publish-assets Artisan commands
- Demo seeder with 3 historical coffee articles
